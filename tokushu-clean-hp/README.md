# 結 清掃のサービスLP

GitHub Pagesで公開する静的LPです。

## サービス構成

- 主なサービスは「特殊清掃」「原状回復」「ハウスクリーニング」の3つです。
- 消臭・消毒・内装リフォームは、お部屋の状態に応じた具体的な作業として説明しています。
- ファーストビューの見出し・説明・CTAはHTMLで編集できます。旧ファーストビュー画像は既存ロゴの表示に使用しています。
- `voices`セクションは、各サービスの相談例です。お客様の体験談や施工実績として扱わないでください。
- 公開元は`gh-pages`ブランチです。`main`と公開元の両方に、対象LPの変更だけを反映してください。

## 見積りフォーム

- 送信先：`ukyou31120807@gmail.com`
- メール送信：FormSubmit（https://formsubmit.co/）
- 初回の送信で届く確認メールの「Activate Form」を受信者が押すと有効になります。有効化前は、LPで送信完了を表示せず、電話相談を案内します。
- お名前・電話番号・ご相談内容が必須です。対応エリアは任意です。
- 件名は「【結 清掃】無料見積りのお問い合わせ」。入力項目は日本語のラベルでメールに届きます。
- JavaScriptが使える場合はAJAXで送信し、受付成功時だけ入力を消去します。通信エラーや有効化待ちでは入力を残します。
- JavaScriptが使えない場合はHTMLの`action`へPOSTします。標準の迷惑送信対策を経て、`thanks.html`へ戻ります。
- 送信先を変える場合は`index.html`のフォーム`action`を変更してください。AJAXの宛先もそこから取得します。

## コピーの改行

文章は意味のまとまりを`copy-unit`で囲み、その間に`wbr`を置いてください。単語の途中に改行位置を作らず、「を」「と」などの助詞は直前の語句と同じまとまりに入れます。送信状況の案内も同じ方式です。
